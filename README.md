# Job Tracker App

A modern, native Android job application tracking app built with **Expo**, **React Native**, **TypeScript**, and **Expo Router**.

---

## 📱 Features

- **Application Log**: Track job applications with statuses (`Saved`, `Applied`, `Interview`, `Offer`, `Rejected`).
- **Kanban Board**: Drag and drop/organize applications visually by stage.
- **Real-Time Analytics & Stats**: View conversion metrics, response rates, and upcoming deadlines.
- **External Job Search**: Quick-launch searches across LinkedIn, Indeed, Naukri, Glassdoor, Internshala, and more.
- **Local-First & Offline**: Complete privacy with data stored locally on your device via AsyncStorage. No cloud logins or external tracking required.
- **Data Export & Import**: Backup or restore your application log using JSON files anytime.

---

## 🛠️ Tech Stack

- **Framework**: Expo (React Native)
- **Language**: TypeScript
- **Navigation**: Expo Router (File-based routing)
- **Storage**: AsyncStorage (Local Device Storage)
- **Icons**: Lucide React Native

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn
- Expo Go app on your Android device OR Android Studio (Emulator)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jyoti-kumbhar/Job_Tracker.git
   cd Job_Tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npx expo start
   ```

4. **Run on Android:**
   - Scan the QR code using the **Expo Go** app on your Android phone, or
   - Press `a` in the terminal to launch on an Android Emulator.
